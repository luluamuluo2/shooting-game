# 方块守卫 · 算术补给站

一个为一年级孩子设计的原创 3D 方块风网页游戏。通过击退可爱僵尸、消耗弹药、解答一道数学题补给武器，让 10 / 20 / 50 以内加减法练习变成小冒险。

## 开始

需要 Node.js 22.12+（或 20.19+）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。构建静态网站：`npm run build`，输出为 `dist/`；本地预览：`npm run preview`。不要直接双击 HTML，需要 HTTP 服务。游戏需要支持 WebGL 的现代浏览器。

## 玩法

- 电脑：WASD / 方向键移动，鼠标转动第一人称视角，屏幕中心准星瞄准，按住左键或空格射击，R 打开补给，ESC 暂停。
- 触屏：左侧方向键移动，拖动画面转视角，右侧射击按钮朝中心准星射击；答题直接点击四个答案选项，不需要输入数字。
- 初始手枪 18 发。子弹用完后，世界暂停，同时给出三道题，**只需任选一道完成**。
- 10 以内题 → 手枪 18 发；20 以内题 → 步枪 36 发；50 以内题 → RPG 5 发范围伤害。
- 加减法操作数和结果均在 0 到对应上限内；没有负数，不含乘除法。
- 答错会显示正确答案，点击“下一题”重试，不扣生命、不倒计时。答对后点击继续，恢复守村；答题期间不消耗防守时间。
- 暂停、切换到后台、答题期间，敌人、刷新、伤害和游戏计时全部冻结。
- 默认关闭音效，不收集个人信息，无登录、广告、付费或联网排行榜。

## 初版范围

采用角色眼睛高度的第一人称视角，镜头不摇晃；鼠标锁定失败时可按住画面拖动转向并用空格射击。答题或暂停时释放鼠标，点击继续重新捕获。模型和地图用程序生成，不使用 Minecraft 素材。僵尸击退效果为彩色方块，没有血腥。当前是单场无限练习原型，不包含联网、存档、关卡编辑或地形破坏；箱子和小屋有简单水平碰撞，场景遮挡子弹；暂不提供跳跃、完整物理或寻路。

## 测试

```bash
npm test                    # 题目范围、边界、武器映射、四选一与随机位置
node tests/qa-runtime.mjs    # 模拟 DOM / renderer 的游戏状态测试，不是浏览器测试

```

可选真实浏览器冒烟脚本：先在另一个终端执行 `npm run dev -- --port 4173`，再运行：

```bash
npx playwright install chromium
node tests/browser.mjs
# 使用已有 Chromium 可设置 CHROMIUM_PATH=/path/to/chromium
```

`tests/browser.mjs` 覆盖空弹夹答题、暂停、答错重试、三种奖励、重复提交和窄屏布局，截图输出在 `test-results/`。

## 技术

Vite + Three.js + 原生 JavaScript / CSS。源代码位于 `src/`，数学规则独立于渲染，方便继续增加年级、难度和武器。依赖版本由 `package-lock.json` 锁定。

## 守村模式更新
- 村民在玩家后方，开场俯瞰可看到；战斗中通过左上角5个圆点与人数获知安全人数，不需要回头。
- 每只怪物最多造成一次防线突破，村民以安全撤离表现，不展示受伤或血腥。玩家不能离开守卫平台，也不能转向后方。
- 全部13种怪物保留HP、速度、坐骑/冲刺与解锁节奏。所有进攻路径避开已有小屋和箱子；泡泡不伤害村民，避免远程与越线重复扣人数。
- 新增逻辑回归：13种怪物前方生成并能到达黄线、同帧多怪突破、归零结束、重开恢复村民、阵地和视角边界、答题期间泡泡完全冻结。模拟渲染测试不等于真实WebGL视觉/触控体验验证。

## 傀儡协防（原创改编数值）
这不是 Minecraft 原版属性。枪械答对1题；补充村民连续答对2题；每种傀儡连续答对3题。答错或切换奖励归零，答错会显示正确答案并换题。答题与领奖期间世界暂停。村民最多5位、傀儡总共最多3只（可重复种类）。若空弹药选择村民或傀儡，成功后附赠手枪18发；否则保留现有枪弹。

## v7 四选一答题
所有枪械、村民、傀儡算术题统一提供4个大按钮：1个正确答案、3个不重复的相邻干扰项（与答案相差不超过5），选项都在0至题目上限内，正确位置随机。点击即判定，无输入框或数字键盘。键盘可用 Tab 聚焦、Enter/空格选择。
枪械1题、村民连续2题、傀儡连续3题不变；答错重置连对进度并显示正确答案。非最终答案保持题目与反馈，手动点击“下一题”后继续，避免双击直接答掉下一题；旧按钮事件失效，长按确认键不重复提交。答题和反馈期间战斗始终暂停。
验证：8项单元测试通过（包含全答案范围和30,000次固定种子位置分布）；完整模拟运行回归通过；生产构建通过。真实WebGL/触屏操作仍需在支持环境试玩，模拟测试不代表真实画面验收。

## v8 随机三选一补给
子弹用完或按 R 都只抽取3张可用的具体补给牌：3种枪械、补充1位村民、6种傀儡。每次先在仍有奖励的类别中等概率选类别，再等概率选该类具体奖励，不放回；因此可以有多把枪、多种傀儡，但不会出现完全相同的牌。村民满5位时排除村民，傀儡满3只时排除所有傀儡；两者都满仍有3把枪可选。不承诺每类必出，也不承诺每次都有枪。
本次牌在切换、答错、下一题时保持不变；关闭后重新打开重新抽取。枪械1题、村民连续2题、傀儡连续3题及四选一答题不变。空弹药不能关闭补给，选非枪械成功仍附赠手枪18发避免卡住。答题中暂停世界，补给卡键盘可选且标示选中状态。

## v9 点选即提交
四个答案点击即判题，支持 Tab + Enter/空格，也可按 1–4 选择。答对反馈 0.9 秒后自动进入下一题或显示补给结果；答错显示正确算式 1.8 秒后自动换题，连续答对进度归零。无需“提交”或“下一题”按钮。补给结果仍由玩家点“继续守卫”恢复战斗，避免答题点击误开枪。
反馈中答案锁定，旧按钮、双击第二次点击及长按按键不重复提交；切补给、退出、重开取消旧过渡。标签页隐藏时保留反馈，回来后再过渡。全部答题/反馈/领奖期间世界冻结。

## v10 战斗节奏、自动返回与傀儡巡逻（当前规则）

- 所有补给弹药减半：手枪 **9 发**、步枪 **18 发**、RPG **3 发**。RPG 原先为 5 发，半数 2.5 向上取整为 3；开局、重开和空弹药领取村民/傀儡后的兜底手枪统一为 9 发。原武器伤害/射速不变，强敌可能需要多轮补给或傀儡协助。
- 僵尸刷新间隔按实际战斗时间从 5.5 秒逐渐缩短，每分钟减少 1 秒：第 1/2/3/4 分钟为 4.5/3.5/2.5/1.5 秒；以后维持 1.5 秒。首只仍在开局 1 秒后出现，同屏最多 8 只，答题和暂停不推进刷新进度。
- 完成奖励所需连答后，保留 0.9 秒正确反馈，再自动回到战斗，不显示或点击“继续守卫”页面。答错仍展示正确算式 1.8 秒，连答重置；中间正确题依旧自动换题。后台页保留反馈直到返回，旧题事件/双击不能重复发奖，恢复时清空按键并保留 0.35 秒射击冷却。
- 傀儡无目标时在前线防区自由巡逻，随机选择可达路线，避开静态障碍，抵达、超时或受阻后换目标；遇敌立即优先战斗，不走入村庄，不离开 x ±6、z -6 至 1.8 的防守区。全部六种傀儡适用，答题/暂停时冻结巡逻。
- 本轮验证：11 项单元测试、完整模拟运行时回归（含六种傀儡各 2 分钟巡逻、碰撞/边界/遇敌、最终反馈与后台/重置取消、开局及兜底弹药）与生产构建通过。真实浏览器由独立 QA 验证；模拟运行不代表画面或实机输入验收。

## v11 全近战傀儡、嘲讽与答错结束（当前规则）

- 六种傀儡全部近战。红石傀儡改为 2 格近战重击，仍为每 2.4 秒 24 伤害；其他傀儡伤害、速度、生命及攻击间隔不变。岩浆傀儡仍须近战命中，再对目标附近 2.5 格造成范围伤害。移除红石远程光束。
- 每种傀儡拥有 **6 格嘲讽半径**。僵尸首次优先选范围内最近的傀儡，随后保持该目标，避免在多个嘲讽圈里抖动换目标；目标退场或离开 6 格范围后重新选择。没有可嘲讽目标时继续冲向村民防线。

## v12 粘液块敌人与粘液块傀儡（当前规则）

- 分裂在原位附近寻找合法位置，避开静态障碍和边界；死去傀儡的嘲讽目标会重新选取小体或其他傀儡。没有可用目标的敌人继续威胁村民。

## v13 六种基础外观傀儡与骑马僵尸速度
