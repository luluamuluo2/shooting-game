# 方块守卫 · 算术补给站

面向一年级孩子的原创 3D 方块风网页游戏：守护村民、击退可爱僵尸，通过 **10 / 20 / 50 以内加减法** 获得战斗补给。模型和地图由程序生成，不使用 Minecraft 素材；无血腥、登录、广告、付费或联网排行榜，默认关闭音效。

历次功能、数值调整和验证记录已集中到 [更新记录](changelog.md)。README 只介绍当前功能与使用方法；完整参数见 [游戏规则](src/rules.js)。

## 安装与运行

需要 Node.js 22.12+（或 20.19+）、npm，以及支持 WebGL 的现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。不要直接双击 HTML，需要通过 HTTP 服务访问。

```bash
npm run build      # 生成 dist/ 静态文件
npm run preview    # 本地预览生产构建
```

部署时托管 `dist/` 的全部内容。项目使用 Vite + Three.js + 原生 JavaScript / CSS，依赖版本由 `package-lock.json` 锁定。

## 操作与答题

- **电脑：** WASD / 方向键移动，鼠标转动第一人称视角，中心准星瞄准，按住左键或空格射击；R 打开补给，Esc 暂停。鼠标锁定不可用时，可按住画面拖动转向。
- **触屏：** 左侧方向键移动，拖动画面转视角，右侧按钮射击；答案直接点选。
- 玩家在固定防守阵地内移动，可360°转头。保护身后的5位村民，每只敌人突破黄色防线撤离1位村民，全部撤离后本局结束。玩家与友军子弹不会伤害村民。
- 开局手枪9发。空弹射击或主动补给时，随机展示3张不同奖励卡，选择其中一张挑战，不必全部完成。
- 枪械答对1题；村民连续答对2题；傀儡和植物连续答对3题。每题4个答案，可点击或按数字键1–4选择。
- 操作数与结果均在对应范围内，没有负数或乘除法。切换奖励重新计数。
- 答对后短暂反馈，自动进入下一题或返回战斗。任意一题答错则结束本轮、不发奖励，显示正确算式后返回战斗；下次主动射击或按R重新挑战，不在原轮重试。
- 空弹完成村民、傀儡或植物奖励后，附赠手枪9发；有弹药时保留原武器弹药。
- 答题、反馈、暂停时，敌人、伤害、弹道、刷新和战斗计时冻结。切到后台暂停战斗，反馈在回到页面后继续。

## 当前战斗内容

### 武器与守村

| 武器 | 题目范围 | 补给弹药 | 单次伤害 | 射击间隔 |
|---|---:|---:|---:|---:|
| 手枪 | 10以内 | 9发 | 10 | 0.35秒 |
| 步枪 | 20以内 | 18发 | 8 | 0.16秒 |
| RPG | 50以内 | 3发 | 中心24，向边缘衰减 | 1.1秒 |

RPG爆炸半径3.5格，场景障碍遮挡伤害。15种常规敌人随战斗时间逐步解锁，另有分裂产生的普通/岩浆小粘液；骑士共享分阶段生命，粘液只分裂一代。普通刷新间隔由5.5秒逐渐缩短至1.5秒，同屏最多30个敌人名额，泰坦占20、大粘液占2，其余各占1。

### 傀儡

13种可召唤傀儡，加上分裂产生的小粘液形态，均为近战，拥有6格嘲讽、巡逻、避障和挥臂动作。最多20名额，普通及大粘液各占1，小粘液各占0.5，最多40只小体。

每种形态理论单目标持续DPS为3.33–3.50；实际输出受接敌、遮挡与存活时间影响。岩浆拥有范围伤害，大粘液死亡分裂为两只不再分裂的小粘液。六种基础傀儡仅外观不同。生命、间隔及各型号参数见 [规则源码](src/rules.js)。

### 植物

8种植物，玩家左右各5个部署位，共10位。连答成功后均匀随机选空位自动部署，无需手选；满位不提供植物奖励。僵尸碰到植物即摧毁，腾出位置。新增两侧最外位在x=±6.5，比普通出生线更靠外，直线前进的普通僵尸不会直接碰到，受傀儡牵引靠近后仍可摧毁。

| 植物 | 伤害 | 攻击间隔 | 效果 |
|---|---:|---:|---|
| 豌豆射手 | 4 | 1.5秒 | 单体直射 |
| 仙人掌 | 7 | 2.5秒 | 白色尖刺，单体直射 |
| 玉米投手 | 5 | 2秒 | 单体抛射 |
| 卷心菜投手 | 6 | 2.5秒 | 叠菜弹丸，单体抛射 |
| 西瓜投手 | 6 | 3.5秒 | 绿皮条纹弹，半径1.5格范围伤害 |
| 冰瓜投手 | 4 | 4秒 | 蓝冰条纹弹，半径1.5格范围伤害及减速 |
| 玉米加农炮 | 16 | 7秒 | 单体抛射 |
| 樱桃投手 | 6 | 3.5秒 | 持续远程抛射，落点半径1.5格爆炸，不自毁 |

全部射程21格，部署后等待一个攻击间隔才首击。按发射时水平距离决定瞄准概率：0–5格100%、>5–10格85%、>10–15格65%、>15–21格45%。打偏有可见弹道，范围伤害按实际落点计算；遮挡和目标失效仍影响最终命中。冰瓜只减速实际受伤且存活的目标，20%减速持续2秒，重复命中刷新而不叠加倍率。

### 地面泰坦

| 泰坦 | 生命 | 移速（格/秒） |
|---|---:|---:|
| 星辉死神 | 1200 | 0.35 |
| 监守者 | 600 | 0.28 |
| 末影龙 | 900 | 0.22 |
| 终极艾德曼毁灭者 | 1100 | 0.25 |
| 终极基岩傀儡泰坦 | 1100 | 0.20 |
| 神·骷髅泰坦 | 800 | 0.30 |
| 执行之龙 | 1000 | 0.22 |
| 凋灵斯拉 | 1000 | 0.24 |
| 终极生命窃魂者 | 950 | 0.28 |

九种均为缓慢地面巨型敌人，本体长宽高均放大为此前2倍（不是生命或伤害翻倍），避障半径3、命中半径2.4格，傀儡可从体表近战。首次在累计战斗90秒尝试出现，之后每次成功出场至少间隔90秒，按表中顺序循环。同屏最多1只；已有泰坦或不足20个空名额时等待，不积压多波。倒计时在临近时改变颜色，不闪烁、不响警报；暂停、在场及满员等待均明确显示。

泰坦兼容嘲讽、近战、植物和范围伤害，对傀儡单次16伤，首击准备0.6秒，随后每1.2秒攻击。突破防线仍仅撤离1位村民；重开清空泰坦并重置计时。

三类巨型傀儡共用宽肩长臂方头凸鼻轮廓，以银红、基岩紫、浅绿裂纹区分；神骷髅保留骷髅骨架；执行之龙保留四足、双翼、分节颈尾；凋灵斯拉保持三方头、横肩、肋骨和脊柱，无四肢。全部为程序化参考重建，不导入 Mod 模型或贴图，不宣称逐顶点还原；执行之龙配色未获原贴图验证，使用本游戏暗灰紫配色。全部贴地移动、受傀儡嘲讽，可被近战攻击，不使用飞行或绕过防线机制。

星辉死神保持最高生命1200。鬼星惊雷不在出场池中。

## 测试

```bash
npm test                    # 规则、植物及实际 index.html 的 jsdom 测试
node tests/qa-runtime.mjs    # 真实 Three 几何 + 模拟 DOM/renderer 的运行回归
npm run build
```

可选浏览器冒烟测试：先在另一个终端执行 `npm run dev -- --port 4173`，再运行：

```bash
npx playwright install chromium
node tests/browser.mjs
# 使用已有 Chromium 可设置 CHROMIUM_PATH=/path/to/chromium
```

截图输出到 `test-results/`。jsdom、几何和模拟运行测试不等于真实 WebGL 画面、帧率、鼠标锁定或手机触控验收；本项目此前的实际浏览器验证受环境限制，详见 [更新记录](changelog.md)。

## 项目结构与范围

- [src/main.js](src/main.js)：场景、战斗、答题和状态流程。
- [src/rules.js](src/rules.js)：算术、单位属性、容量和时间规则。
- [src/plants.js](src/plants.js)：植物模型、弹道和伤害。
- [src/titans.js](src/titans.js)：原创泰坦模型。
- [tests](tests)：规则、DOM、运行与浏览器测试。
- [changelog.md](changelog.md)：完整保留的历史说明和版本更新记录。

当前是单场无限练习原型，不含联网、存档、关卡编辑或地形破坏；采用简化碰撞和避障，不提供跳跃或完整物理模拟。
