# 方块守卫 · 算术补给站

一个为一年级孩子设计的原创 3D 方块风网页游戏。通过击退可爱僵尸、消耗弹药、解答一道数学题补给武器，让 10 / 20 / 50 以内加减法练习变成小冒险。

## 开始

需要 Node.js 22.12+（或 20.19+）。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。构建静态网站：`npm run build`，输出为 `dist/`；本地预览：`npm run preview`。不要直接双击 HTML，需要 HTTP 服务。游戏需要支持 WebGL 的现代浏览器。

## 玩法

- 电脑：WASD / 方向键移动，鼠标转动第一人称视角，屏幕中心准星瞄准，按住左键或空格射击，R 打开补给，ESC 暂停。
- 触屏：左侧方向键移动，拖动画面转视角，右侧射击按钮朝中心准星射击；答题支持屏幕数字键盘。
- 初始手枪 18 发。子弹用完后，世界暂停，同时给出三道题，**只需任选一道完成**。
- 10 以内题 → 手枪 18 发；20 以内题 → 步枪 36 发；50 以内题 → RPG 5 发范围伤害。
- 加减法操作数和结果均在 0 到对应上限内；没有负数，不含乘除法。
- 答错可以重试或换一题，不扣生命、不倒计时。答对后点击继续，恢复守村；答题期间不消耗防守时间。
- 暂停、切换到后台、答题期间，敌人、刷新、伤害和游戏计时全部冻结。
- 默认关闭音效，不收集个人信息，无登录、广告、付费或联网排行榜。

## 初版范围

采用角色眼睛高度的第一人称视角，镜头不摇晃；鼠标锁定失败时可按住画面拖动转向并用空格射击。答题或暂停时释放鼠标，点击继续重新捕获。模型和地图用程序生成，不使用 Minecraft 素材。僵尸击退效果为彩色方块，没有血腥。当前是单场无限练习原型，不包含联网、存档、关卡编辑或地形破坏；箱子和小屋有简单水平碰撞，场景遮挡子弹；暂不提供跳跃、完整物理或寻路。

## 测试

```bash
npm test                    # 题目范围、边界、武器映射、输入校验
node tests/qa-runtime.mjs    # 模拟 DOM / renderer 的游戏状态测试，不是浏览器测试
npm run build
```

可选真实浏览器冒烟脚本：先在另一个终端执行 `npm run dev -- --port 4173`，再运行：

```bash
npx playwright install chromium
node tests/browser.mjs
# 使用已有 Chromium 可设置 CHROMIUM_PATH=/path/to/chromium
```

`tests/browser.mjs` 覆盖空弹夹答题、暂停、答错重试、三种奖励、重复提交和窄屏布局，截图输出在 `test-results/`。

本次开发验证：6 项自动单元测试通过；模拟运行时测试通过；生产构建通过。真实 WebGL 和手机试玩的验证限制见文末。

## 技术

Vite + Three.js + 原生 JavaScript / CSS。源代码位于 `src/`，数学规则独立于渲染，方便继续增加年级、难度和武器。依赖版本由 `package-lock.json` 锁定。

## 13 种怪物与战斗平衡（2026-11-14）
这是一组原创方块造型和儿童友好的改编机制，不是 Minecraft 原版数值/完整行为复刻。生命值统一重标定；不再采用原先普通怪 2 HP 的尺度。

| 武器 | 单次伤害 | 射击间隔 | 理论持续 DPS | 答题补给 | 射程 |
|---|---:|---:|---:|---:|---:|
| 手枪 | 10 | 0.35秒 | 28.6 | 18发 | 30单位 |
| 步枪 | 8 | 0.16秒 | 50 | 36发 | 30单位 |
| RPG | 中心24，边缘约12 | 1.1秒 | 中心21.8/目标 | 5发 | 30单位 |

DPS不含补给/瞄准/漏弹。RPG半径3.5，线性衰减并取整，范围外0；每目标每发只结算一次，不叠加直接伤害，房屋/箱子等场景几何遮挡爆炸。武器的 `range` 字段是**算术范围**，不是射程。

| 怪物 | HP | 常态速度（单位/秒） | 手枪/步枪/RPG中心命中次数 | 最早解锁（游玩秒） |
|---|---:|---:|---|---:|
| 普通僵尸 | 40 | 0.8 | 4 / 5 / 2 | 0 |
| 小僵尸 | 20 | 1.3 | 2 / 3 / 1 | 20 |
| 尸壳 | 50 | 0.65 | 5 / 7 / 3 | 35 |
| 僵尸村民 | 40 | 0.7 | 4 / 5 / 2 | 50 |
| 溺尸 | 40 | 0.7 | 4 / 5 / 2 | 65 |
| 装甲僵尸 | 80 | 0.55 | 8 / 10 / 4 | 80 |
| 僵尸猪灵 | 50 | 1.0 | 5 / 7 / 3 | 95 |
| 僵尸马 | 60 | 1.4 | 6 / 8 / 3 | 110 |
| 鸡骑士 | 20坐骑+20骑手 | 1.35→1.3 | 4 / 5 / 2 | 125 |
| 尸壳骆驼 | 80 | 0.85 | 8 / 10 / 4 | 140 |
| 僵尸鹦鹉螺 | 60 | 0.55 | 6 / 8 / 3 | 155 |
| 骑马僵尸 | 60坐骑+40骑手 | 1.25→0.8 | 10 / 13 / 5 | 170 |

- 命中次数假设全中、RPG始终中心，骑士采用共享两阶段生命池，溢出伤害保留；不支持独立瞄准骑手绕过坐骑。
- 普通怪从第一发命中到击退理论耗时：手枪1.05秒、步枪0.64秒、RPG1.1秒。实际还受帧时间、瞄准、距离和失误影响。
- 溺尸/鹦鹉螺：1.2秒黄色预警后发射速度3的慢泡泡，冷却6秒，泡泡最长8秒且会被房屋/箱子挡住；守村模式中泡泡仅为装饰，在黄线处消失，不额外扣村民。同屏最多1只远程怪。鹦鹉螺改为低空漂浮，当前无水域生态。
- 骆驼/疣猪兽：1.2秒预警后向预警时的位置直线冲刺0.85秒，速度3，冷却6秒。同屏最多1只冲刺怪。
- 猪灵在守村模式中改为主动入侵者，与其他怪物一样向防线前进；不沿用原版中立行为。
- 装甲通过高HP表现，无额外暗藏减伤。村民暂无治愈系统；尸壳无饥饿惩罚；不实现日照燃烧、掉落、疾病或血腥效果。
- 最多8只怪物，生成间隔由5.5秒缓慢降至3.5秒。新类型优先出现但出生点必须离玩家7单位以上，故表中为最早时间，不是精确时间保证。难度只由实际游玩时间变化，答题时不流逝。
- 玩家速度4.2，仅在 x∈[-5,5]、z∈[6,8] 的阵地内移动，朝向限制为正前方左右各75°。后方 z=11 有5位村民；怪物从 x≈-4/0/4、z∈[-16,-14] 三路进场，越过 z=3 的黄线即撤走1位村民并移除该怪物（不计击杀）；同帧多只分别扣除，没有受击无敌吞掉突破。0位村民结束本局。村民不受玩家子弹和RPG影响，玩家不再受伤。答题/暂停冻结怪物、预警、冲刺、泡泡及出生计时。手枪一匣180伤害，可应对所有单怪。

### 验证
`npm test`：6项通过，包括30,000道算术题、13种属性、解锁和并发限制、爆炸衰减。
`node tests/qa-runtime.mjs`：真实Three几何、模拟DOM/渲染器的逻辑测试通过，含13种生成/死亡/坐骑退场、守村猪灵主动前进、预警、8怪上限、答题冻结、FPS瞄准/键盘/多指逻辑。
`npm run build`通过。
云浏览器实际打开本地预览，显示 WebGL 不可用；控制台明确 GL_VENDOR/GL_RENDERER Disabled。因此当前环境**不能验证真实3D渲染/流畅度/鼠标锁定/手机手感**，这些逻辑测试不能替代真人试玩。浏览器回归脚本保留供具备WebGL的环境使用。

## 守村模式更新
- 村民在玩家后方，开场俯瞰可看到；战斗中通过左上角5个圆点与人数获知安全人数，不需要回头。
- 每只怪物最多造成一次防线突破，村民以安全撤离表现，不展示受伤或血腥。玩家不能离开守卫平台，也不能转向后方。
- 全部13种怪物保留HP、速度、坐骑/冲刺与解锁节奏。所有进攻路径避开已有小屋和箱子；泡泡不伤害村民，避免远程与越线重复扣人数。
- 新增逻辑回归：13种怪物前方生成并能到达黄线、同帧多怪突破、归零结束、重开恢复村民、阵地和视角边界、答题期间泡泡完全冻结。模拟渲染测试不等于真实WebGL视觉/触控体验验证。
