# 方块守卫 · 算术补给站

面向一年级孩子的原创 3D 方块风网页游戏：守护村民、击退可爱僵尸，通过 **10 / 20 / 50 以内加减法** 获得战斗补给。模型和地图由程序生成，不使用 Minecraft 素材；无血腥、登录、广告、付费或联网排行榜，默认关闭音效。

历次功能、数值调整和验证记录已集中到 [更新记录](changelog.md)。README 只介绍当前功能与使用方法；完整参数见 [游戏规则](src/rules.js)。

## 安装与运行

需要 Node.js 22.12+（或 20.19+）、npm，以及支持 WebGL 的现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。不要直接双击 HTML，需要通过 HTTP 服务访问。

```bash
npm run build      # 生成 dist/ 静态文件
npm run preview    # 本地预览生产构建
```

部署时托管 `dist/` 的全部内容。项目使用 Vite + Three.js + 原生 JavaScript / CSS，依赖版本由 `package-lock.json` 锁定。

## 操作与答题

- **电脑：** WASD / 方向键移动，鼠标转动第一人称视角，中心准星瞄准，按住左键或空格射击；R 打开补给，Esc 暂停。鼠标锁定不可用时，可按住画面拖动转向。
- **触屏：** 左侧方向键移动，拖动画面转视角，右侧按钮射击；答案直接点选。
- 玩家在固定防守阵地内移动，可360°转头。保护身后的5位村民，每只敌人突破黄色防线撤离1位村民，全部撤离后本局结束。玩家与友军子弹不会伤害村民。
- 开局手枪9发。空弹射击或主动补给时，展示3张不同奖励卡；植物有空位必含植物，傀儡有完整空名额必含傀儡，其余随机，选择其中一张挑战，不必全部完成。
- 枪械答对1题；村民连续答对2题；普通傀儡和植物连续答对3题；超级傀儡4题召唤2只，终极傀儡5题召唤3只。每题4个答案，可点击或按数字键1–4选择。
- 操作数与结果均在对应范围内，没有负数或乘除法。切换奖励重新计数。
- 答对后短暂反馈，自动进入下一题或返回战斗。任意一题答错则结束本轮、不发奖励，显示正确算式后返回战斗；下次主动射击或按R重新挑战，不在原轮重试。
- 空弹完成村民、傀儡或植物奖励后，附赠手枪9发；有弹药时保留原武器弹药。
- 答题、反馈、暂停时，敌人、伤害、弹道、刷新和战斗计时冻结。切到后台暂停战斗，反馈在回到页面后继续。

## 当前战斗内容

### 武器与守村

| 武器 | 题目范围 | 补给弹药 | 单次伤害 | 射击间隔 |
|---|---:|---:|---:|---:|
| 手枪 | 10以内 | 9发 | 10 | 0.24秒/轮（三连发） |
| 步枪 | 20以内 | 18发 | 8 | 0.12秒/轮（三连发） |
| RPG | 50以内 | 3发 | 中心24，向边缘衰减 | 1.1秒 |

RPG爆炸半径3.5格，场景障碍遮挡伤害。15种常规敌人随战斗时间逐步解锁，另有分裂产生的普通/岩浆小粘液；骑士共享分阶段生命，粘液只分裂一代。普通刷新间隔由5.5秒逐渐缩短至1.5秒，同屏最多100个敌人名额，泰坦占20、大粘液占2，其余各占1。

### 傀儡

13种可召唤傀儡，加上分裂产生的小粘液形态，均为近战，拥有6格嘲讽、巡逻、避障和挥臂动作。最多50名额，普通及大粘液各占1，小粘液各占0.5，最多100只小体。

每种形态理论单目标持续DPS为3.33–3.50；实际输出受接敌、遮挡与存活时间影响。岩浆拥有范围伤害，大粘液死亡分裂为两只不再分裂的小粘液。六种基础傀儡仅外观不同。生命、间隔及各型号参数见 [规则源码](src/rules.js)。

### 植物

8种植物，玩家左右各5个部署位，共10位。连答成功后均匀随机选空位自动部署，无需手选；满位不提供植物奖励。僵尸碰到植物即摧毁，腾出位置。新增两侧最外位在x=±6.5，比普通出生线更靠外，直线前进的普通僵尸不会直接碰到，受傀儡牵引靠近后仍可摧毁。

| 植物 | 伤害 | 攻击间隔 | 效果 |
|---|---:|---:|---|
| 豌豆射手 | 4 | 1.5秒 | 单体直射 |
| 仙人掌 | 7 | 2.5秒 | 白色尖刺，单体直射 |
| 玉米投手 | 5 | 2秒 | 半径1格群体抛射 |
| 卷心菜投手 | 6 | 2.5秒 | 叠菜弹丸，半径2格群体抛射 |
| 西瓜投手 | 6 | 3.5秒 | 绿皮条纹弹，半径2格范围伤害 |
| 冰瓜投手 | 4 | 4秒 | 蓝冰条纹弹，半径5格范围伤害及减速 |
| 玉米加农炮 | 16 | 7秒 | 半径5格群体抛射 |
| 樱桃投手 | 6 | 3.5秒 | 持续远程抛射，落点半径2格爆炸，不自毁 |

全部射程21格，部署后等待一个攻击间隔才首击。按发射时水平距离决定瞄准概率：0–5格100%、>5–10格85%、>10–15格65%、>15–21格45%。打偏有可见弹道，范围伤害按实际落点计算；遮挡和目标失效仍影响最终命中。冰瓜只减速实际受伤且存活的目标，20%减速持续2秒，重复命中刷新而不叠加倍率。

### 地面泰坦

| 泰坦 | 生命 | 移速（格/秒） |
|---|---:|---:|
| 监守者 | 600 | 0.28 |
| 神·骷髅泰坦 | 800 | 0.30 |
| 末影龙 | 900 | 0.22 |
| 终极生命窃魂者 | 950 | 0.28 |
| 终极基岩傀儡泰坦 | 1000 | 0.20 |
| 终极艾德曼毁灭者 | 1100 | 0.25 |
| 星辉死神 | 1200 | 0.35 |
| 执行之龙 | 1300 | 0.22 |
| 凋灵斯拉 | 1400 | 0.24 |

九种均为缓慢地面巨型敌人，首轮本体长宽高为原始模型累计4倍（不是生命或伤害翻倍），避障半径6、命中半径4.8格，傀儡可从体表近战。首次在累计战斗90秒尝试出现，之后每次成功出场至少间隔90秒，按表中顺序循环。同屏最多1只；已有泰坦或不足20个空名额时等待，不积压多波。倒计时在临近时改变颜色，不闪烁、不响警报；暂停、在场及满员等待均明确显示。

泰坦兼容嘲讽、近战、植物和范围伤害，对傀儡第1轮单次16伤，之后每轮翻倍，首击准备0.6秒，随后每1.2秒攻击。突破防线仍仅撤离1位村民；重开清空泰坦并重置计时。

三类巨型傀儡共用宽肩长臂方头凸鼻轮廓，以银红、基岩紫、浅绿裂纹区分；神骷髅保留骷髅骨架；执行之龙保留四足、双翼、分节颈尾；凋灵斯拉保持三方头、横肩、肋骨和脊柱，无四肢。全部为程序化参考重建，不导入 Mod 模型或贴图，不宣称逐顶点还原；执行之龙配色未获原贴图验证，使用本游戏暗灰紫配色。全部贴地移动、受傀儡嘲讽，可被近战攻击，不使用飞行或绕过防线机制。

星辉死神保持最高生命1200。鬼星惊雷不在出场池中。

## 植物升级与立即挑战泰坦
- 每株独立成长，死亡/重开丢失。补给新增“具体植物＋升级效果”卡，连续答对2题，同类型中随机选择尚未封顶的一株；题目范围沿用该植物。全部8种植物均可升级多重射击；直射单体（豌豆、仙人掌）还可升级减速，六种群体抛射还可升级范围和减速。无额外次数限制，直到对应上限；每次答错整轮失败。满10植物位仍可升级；未满时新植物保底与傀儡保底保持独立，升级争取剩余随机卡位。
- 多重：每级+1颗，上限100颗/轮，每颗原伤害且独立MISS；有多敌按接近防线顺序循环分散，无其他敌可全部攻击同一Boss。不改变间隔。
- 范围：每级增加初始半径300个百分点，最多3次，倍率100%→400%→700%→900%封顶，实际半径依题目难度：1→4→7→9；2→8→14→18；5→20→35→45；第3次受900%上限截断，不是复利。范围内全额伤害、遮挡与MISS保持原规则。
- 减速：升级强度从0开始，每次+100个百分点，最多3次到300%。普通植物实际减速0→10%→20%→30%；冰瓜初始20%独立保留，三次升级实际20%→40%→60%→80%，每一级都有收益。所有泰坦实际减速最多50%。同一敌人取尚未过期最强效果并刷新2秒，不相加；到期恢复基础速度。只减移动速度。
- 正在飞行的弹丸使用发射时的升级快照；升级不修改基础配置/图鉴原模型。每颗独立实体，无人为削减100发上限。植物成长详情可查看当前效果。
- “立即挑战下一位泰坦”按钮（桌面B键）仅战斗中可用，遵守9Boss顺序，同场最多1只。手动立即生成，不删除/替换任何现有普通怪；即使剩余名额不足20也允许暂时超过100，最多100普通名额+20Boss=120名额，超限期间停普通刷新，降回可用名额后正常继续。自动刷新仍受100总名额限制。
- 无论手动或自动，成功出场后从当前战斗计时重新计90秒；暂停、答题、图鉴和已有Boss时不能手动召唤；重复触发不叠加。

## 三连射与100敌人名额
手枪每轮触发间隔0.24秒，三连发内间隔0.045秒；步枪每轮0.12秒，轮内0.03秒。每轮最多3发，每颗独立按当时准星和遮挡结算并消耗1弹；余1/2弹只发1/2颗，最后一发耗尽后进入答题。按住连续触发，无需反复点击。暂停、打开补给、重开都会取消尚未发出的连发，不补扣弹；答题中不会继续发射。RPG仍单发1.1秒，伤害/弹量均不变。三连发理论持续DPS（不含答题和中断）手枪125、步枪200，单发伤害仍10/8。
敌人名额100，泰坦20、普通大粘液2、小体及其余1；自动Boss需要至少20空位。单Boss规则不变，手动立即挑战保留旧怪且可临时最多120名额；达到或超过100后普通刷新暂停，空位足够才恢复。

## 泰坦轮次成长
- 以成功出场数计轮，九种Boss按基础HP从低到高稳定排序循环（同HP保留原相对顺序）。第1–9只属于第1轮，第10–18只属于第2轮，第19只进入第3轮。第9只出现时仍是第1轮，第10只成功出场才升级全场轮次。击杀或突破后均可继续，不要求击杀九种。手动/自动统一计数；失败触发不计数；重开回第1轮。
- 第n轮泰坦最大/初始生命为配置基础HP × 2^(n−1)。例如星辉死神1200→2400→4800；攻击伤害同样为16×2^(n−1)，速度、攻击间隔、大小、20名额不变。图鉴和基础属性表仍展示第1轮配置。HUD同时显示轮次与实际当前/最大HP。
- 普通刷怪不再由Boss出场轮次加速，而是每实际击败一只定时泰坦，频率立即×1.5：间隔=max(1.5,5.5−elapsed/60)÷1.5^击败数，剩余刷新等待同时÷1.5。基础间隔1.5秒时，击败0/1/2/3只分别1.5/1/0.6667/0.4444秒。逃脱、移除、重复死亡调用和普通疣猪兽不计；手动/自动出场的泰坦同等计数，重开归零。Boss每9出场血量翻倍独立保留，Boss90秒周期不变，暂停/答题不推进计时。HUD显示击败数和刷怪倍率。
- 高频刷新支持同帧多次出场，但每帧最多尝试当前空名额数（不超过100）；满员时丢弃过期刷新机会，不积攒无限队列。普通刷新仍受100名额限制；现有手动Boss立即挑战最多临时120名额例外不变。时间间隔小于浮点可表示范围后按可用名额补足，不设置人为击败数/倍率上限。
- 极高轮Boss生命使用BigInt定点值（百万分之一HP精度）保存和扣减，避免Infinity及微小伤害被大数字吞掉；很长的HP用科学计数法展示，血条用比例计算。无玩法轮数上限，但设备运算/内存仍是物理限制，不承诺任意大轮数性能。

## 植物攻击动作
8种植物保留原模型，在发射前最后0.24秒有目标时蓄力，原定发射时刻立即出弹并播放0.32秒回弹。豌豆鼓起/缩口后坐，仙人掌侧摆刺射，玉米后仰抛投，卷心菜扭转甩叶，西瓜重摆投掷，冰瓜轻膨胀冰光回弹，樱桃压缩跳弹，玉米加农炮炮管抬起后坐。每轮一组短促轻量发射光圈/颗粒，多发升级不会重复叠100组闪光。
仅上部外观节点变换，底座和植物根位置不动，不改变接触判定、弹道起点、射程、伤害、攻击间隔、MISS抽样或升级；蓄力不是额外延迟，无目标不空蓄力。暂停/答题冻结动作，消失/重开清理。图鉴植物页循环演示动作，不生成实弹、不影响战斗。所有动作与特效均为现有模型及程序几何，不使用第三方素材。

## 神·骷髅泰坦双刃战斧
神·骷髅泰坦的棕弓替换为长柄双刃巨斧：灰白骨色刃面、暗金斧心和握柄装饰，左右对称刃形，区别星辉死神的蓝色单侧镰刀。骷髅头、胸肋、腿和手臂原比例不改；右臂与斧共同转动。接敌伤害结算前最后0.35秒举斧蓄势，结算后0.4秒下劈/归位；动作仅表现，原首击0.6秒、重复1.2秒、基础16伤害、既有HP/轮次/碰撞机制不由动作改变；实际攻击伤害现按轮次翻倍。图鉴直接使用同一个巨斧模型，无额外第三方素材；这一武器为本游戏定制，并非原Mod武器复刻。

## 全部抛射植物群攻与植物投石车
